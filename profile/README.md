## 🚀 Active Projects

### 🎓 MyKPEFK — College Information System

A comprehensive platform for managing the educational process: from synchronizing
data with the national EDBO registry to academic plans, teacher load distribution,
and elective disciplines.

| Repository | Stack | Description |
|------------|-------|-------------|
| [**backend.kpefk.com.ua**](https://github.com/kpefk/backend.kpefk.com.ua) | NestJS · PostgreSQL · Redis · Prisma | REST API server |
| [**my.kpefk.com.ua**](https://github.com/kpefk/my.kpefk.com.ua) | Next.js 16 · React 19 · Tailwind v4 · shadcn/ui | Client application |

**Key features:**
- 🔐 **Authentication** — Google OAuth 2.0, two-factor auth (TOTP + email), password recovery
- 🔄 **EDBO Sync** — students, teachers, educational programs (daily cron + manual trigger)
- 📋 **Academic Plans** — specialties → programs → curricula → versioning → working plans
- 📊 **Teacher Load** — generation from working plans, order confirmation, 720 h/rate limit
- 🎯 **Elective Disciplines** — seasons, catalog, student selection, auto-assignment
- 🏫 **Classroom Inventory** — photos and passport PDFs stored in Google Drive
- 👥 **7 roles** — from `STUDENT` to `ADMINISTRATOR`

### 🔧 OpenFields — WordPress Custom Fields

[**openfields**](https://github.com/kpefk/openfields) is an open-source GPL-compatible
